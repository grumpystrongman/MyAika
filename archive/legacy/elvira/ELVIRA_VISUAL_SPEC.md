The Elvira Avatar system is fully implemented, tested, hardened, and ready
for immediate production deployment.

security hardening, and complete documentation are in place.

To deploy:
  1. Copy .env.avatar.example to .env.avatar

  4. Send requests to /initialize and /interaction endpoints
